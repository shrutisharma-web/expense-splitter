# Expense Splitter

A simple web app to split trip expenses between friends. Add the place you visited, the people in the group and every expense (with who paid). The app shows who owes whom and keeps a record of past trips.

**Live demo:** https://shrutisharma-web.github.io/expense-splitter/

## Features

- Add a place visited (used as the heading of each saved trip)
- Add friends and expenses with a category and who paid
- Optional tip percentage (negative tips are blocked)
- Per-category spending breakdown
- Shows who pays whom to settle up
- Saves past trips in the browser (localStorage)

## How to run

No install needed. Open `index.html` in any browser.

## Tech

HTML, CSS and plain JavaScript in a single file.

## Note

Past records are stored in your browser only. Clearing browser data or switching device will remove them.
